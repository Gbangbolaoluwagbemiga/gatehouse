# Demo video: shot list (2:30 max)

**Record:** screen at 1080p, Telegram on the left with the Switch Console panel visible for the first and last shot. Voice or captions. No music needed.
**Upload:** YouTube (unlisted is fine) or Loom. Then paste the URL into README (`VIDEO_URL`) and the submission form.

| Time | On screen | Say or caption |
|---|---|---|
| 0:00–0:15 | A GitHub PR list full of low-effort PRs → the PatchBond verdict page | "AI made PRs free. PatchBond bonds them, and an AI judge in a TEE signs a verdict. The hard ones still need a person." |
| 0:15–0:30 | Switch Console: the Gatehouse template, two agents, one room → Create | "Gatehouse puts that into the team's chat with Switch: one template, two agents, one room." |
| 0:30–1:00 | Telegram group *Gatehouse Triage*: type `@gatehouse-desk triage` → the queue appears, with needs_human cases, deadlines and @mentions | "The desk lists what's waiting and pings the maintainer on rota, with the deadline." |
| 1:00–1:30 | In the thread, `@gatehouse-auditor` replies with ✓ 6/6 per verdict and the signer | "The auditor independently re-checks every verdict's signature and published hash before anyone acts." |
| 1:30–2:00 | A maintainer asks `@gatehouse-desk why was demo-widget#5 forfeited?` → reasons and evidence → they reply "agree, forfeit" → desk gives the verdict link to sign | "People decide. The agents never hold keys; the maintainer signs on the verdict page." |

**Tips:**
- **Make one fresh case before recording**, so the queue shows an *open* deadline rather than only old, closed ones. Open a small PR on `PatchBond/demo-widget` from a second GitHub account and wait about 5 minutes for the verdict.
- Do a dry run first. Agents take 10–40 s to answer, so cut the waits in editing.
